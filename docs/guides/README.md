# Guides

Each guide covers one task. The commands run on a copy of your game's files, and each step shows the output to expect. Start with getting started.

| Guide | Task |
|---|---|
| [Getting started](getting-started.md) | Find the game's files, make a working copy, and read the archive layout. |
| [Editing script text](editing-text.md) | Export the script text, change a line, import it, and rebuild the archive. |
| [Editing scripts](editing-scripts.md) | Dump a compiled script to text, edit it, assemble it, and rebuild the archive. |
| [Compiling a Switch script](compile-a-switch-script.md) | Compile a Switch script to a Steam script and rebuild the archive. |
| [Editing images](editing-images.md) | Convert background images and CompressedBG images to PNG and back. |
| [Editing audio](editing-audio.md) | Unwrap and wrap `.hw` audio, and convert a Switch clip for the game. |
| [Editing fonts](editing-fonts.md) | Export a glyph table, edit it, and render a line from its atlases. |
| [Reading Switch archives](switch-files.md) | List, unpack and decode the Switch archive sets, textures and scripts. |
| [Repacking an archive](repacking.md) | Rebuild an HFA archive with `--base` and confirm the result. |

The command reference is in [../cli.md](../cli.md). The file format descriptions are in [../formats/](../formats/).
