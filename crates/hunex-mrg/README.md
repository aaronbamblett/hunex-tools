# hunex-mrg

Reader for the MRG archive sets of the HuneX Switch RomFS: a `.hed` index of 8-byte rows, a `.mrg` data file, and a `.nam` file of names. The crate is `no_std`, has no dependencies, and builds for WebAssembly.

Part of the [hunex-tools](https://github.com/aaronbamblett/hunex-tools) project. Unofficial; not affiliated with HuneX. The crate does not include any game data.
