# hunex-cli

The `hunex` command for HuneX engine files: `hunex chs dump`, `hunex chs roundtrip`, `hunex chs asm`, `hunex hfa list`, `hunex hfa unpack`, `hunex hfa pack`, `hunex lenzu decompress` and `hunex lenzu compress`. Install with `cargo install hunex-cli`.

Part of the [hunex-tools](https://github.com/aaronbamblett/hunex-tools) project. Unofficial; not affiliated with HuneX or TYPE-MOON. The tool does not include any game data; supply your own files.
