# hunex-ogg

Ogg page reader and writer for the hunex audio crates. Reading checks each page's CRC-32; writing computes it. The crate is `no_std`, has no dependencies, and builds for WebAssembly.

Part of the [hunex-tools](https://github.com/aaronbamblett/hunex-tools) project. Unofficial; not affiliated with HuneX or TYPE-MOON. The crate does not include any game data.
